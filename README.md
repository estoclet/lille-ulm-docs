# Lille ULM docs

Depot de documentation, cadrage et pilotage pour la refonte Lille ULM.

## Repos du projet

- repo documentaire : `lille-ulm-docs`
- repo applicatif : `lille-ulm-drupal-app`
- details de checkout et URL Git : `framework-refonte-drupal-ia/00-initialisation-projet.md`

## Contenu

- rapports sur l'existant Joomla ;
- documentation gestionnaire ;
- cadre de refonte Drupal assistee par IA ;
- templates et gouvernance projet ;
- page client de suivi publiee via GitHub Pages.

## Reperes

- framework IA : `framework-refonte-drupal-ia/`
- analyse de l'existant : `refonte-site/`
- page client : `docs/index.html`

## Suivi projet

Le backlog operationnel vit dans les GitHub Issues du depot.

Les tickets visibles cote client portent le label `client`.

Les task packs actifs sont a la racine du depot (`task-pack-*.md`).
Valider, rendre ou dispatcher un pack : `python3 framework-refonte-drupal-ia/orchestrateur.py --help`
